# Reproducible Numerical Checks

Inventory values, units, denominators, currencies/exchange dates, periods, bounds, uncertainty and source ranges. Separate stocks/flows, annual/cumulative figures, percentages/percentage points and measurements/estimates. Reconcile tables, charts and prose: totals, subtotals, weights, rates, duplicates, omissions and broken formulas. State rounding tolerance before concluding error. Check eligibility/exclusions in each denominator, including failures, timeouts and abstentions; averaging rates needs a weighting rule matching the metric definition.

Use `python3 PATH/scripts/check_numbers.py arithmetic-input.json quality/arithmetic-results.json`. Input is an array of objects: id, operation (sum, difference, product, ratio, percent or weighted_mean), values (decimal strings), unit, reported (decimal string), tolerance (nonnegative decimal string), sourceRefs (nonempty record IDs), and missingPolicy (`reject`). weighted_mean also needs weights. Difference and ratio require exactly two operands; percent is 100 * numerator / denominator. Results include operands, formula, actual, difference, tolerance and withinTolerance. A missing operand or zero denominator yields unavailable with a reason, not a false numerical defect. Decimal precision is 40 significant digits; scientific notation is accepted, nonfinite values and executable formulas are not. The helper never opens source documents or decides that the formula is correct.

Preserve the input file and output in quality/ and cite both from an executed numeric check with formula, unit, missingPolicy, rounding rule and verified locators. Independently validate the formula against the indicator definition and useful simple cases. Distinguish declared and recomputed values and explain the decision consequence. Without data, report non-reproducibility rather than a wrong answer.

For chronology normalize time zones; distinguish execution, registration and approval. Ordering matters only for a real dependency/requirement. For sensitivity use justified assumption ranges and identify recommendation-switch thresholds; invented exploratory ranges are scenarios, not probability estimates. Review axes/scales/units/intervals/baselines and correspondence to data. A truncated axis is a defect only with argued material misleading effect.
