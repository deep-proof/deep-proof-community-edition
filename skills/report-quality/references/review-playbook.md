# Rigorous Verification Playbook

Apply [Common Protocol](protocol.md), [Domain Profiles](profiles.md), [Defect Taxonomy](taxonomy.md), [Data Contracts](contracts.md), [Numerical Checks](numerical.md) and [Report Template](report-template.md). The supplied mandate bounds the review; profile activation and criteria applicability require reasons. Record claims, requirements, evidence, executed tests, omission searches, challenged candidates and honest coverage. Confirm only evidence-backed defects surviving a favorable-author explanation and original-source review. Serious confirmations need a distinct revisit. Preserve unknowns, allow zero confirmed findings and distinguish completed work from full substantive assurance. This methodology has not been validated and is not safe for real-world problems without rigorous validation.
